# 🦆 Bebek Tech POS (Point of Sale & Admin Dashboard)

Sistem Point of Sale (POS) dan Dashboard Admin modern yang dirancang khusus untuk operasional restoran cepat saji (khususnya menu spesialis bebek dan olahan nusantara). Dibangun dengan fokus pada kecepatan transaksi kasir, antarmuka yang bersih (*clean UI*), serta navigasi interaktif ala perusahaan teknologi masa kini.

🔗 **Live Demo:** [Demo website](https://prototype-web-bebek.vercel.app/)

---

## ✨ Fitur Utama

1. **Halaman Kasir (POS Interface):**
   * Tautan interaktif antara katalog produk (Grid Menu) dan keranjang belanja (*Smart Cart*).
   * Mendukung tipe layanan **Dine In (Makan Sini)** dan **Take Away (Bungkus)**.
   * Penghitungan total harga otomatis secara *real-time*.
2. **Riwayat Transaksi:**
   * Tabel histori pesanan lengkap dengan informasi status pembayaran (*Sukses*, *Pending*).
   * Fitur filter dan tampilan responsif untuk memantau transaksi harian.
3. **Manajemen Menu (CRUD Mockup):**
   * Daftar menu terstruktur dengan pengelolaan kategori (Makanan & Minuman) beserta harga dan ikon produk.
4. **Laporan Pendapatan (Analytics):**
   * Ringkasan metrik penting (Total Pendapatan, Jumlah Transaksi, Menu Terfavorit).
   * Tabel rincian produk terjual untuk evaluasi performa outlet.
5. **UI/UX Modern & Interaktif:**
   * Animasi Sidebar responsif yang dapat dibuka/tutup secara mulus.
   * *Skeleton Loading* interaktif saat pertama kali halaman dimuat untuk pengalaman pengguna yang optimal.
